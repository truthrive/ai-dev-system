# Roadmap

## M1 — Core Operating Model

Make the development lifecycle executable with technology-agnostic rules, skills, and distinct feature, bugfix, and refactor workflows.

## M2 — Enforcement & Project Onboarding

Add deterministic enforcement and a practical way to adopt the system in new, active, and legacy projects.

## M3 — Real Project Validation

Apply the system across representative projects, capture evidence, and refine it from observed gaps and repeated needs.

## M4 — Distribution & v1.0

Package a stable, documented release that can be distributed, installed, updated, and used consistently across supported coding agents.
