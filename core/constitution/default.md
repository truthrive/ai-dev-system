# Default constitution

1. Think before coding.
2. Prefer the simplest sufficient solution.
3. Make surgical changes.
4. Inspect source and runtime before trusting descriptive documentation.
5. Do not refactor unrelated code.
6. Define success criteria before implementation.
7. Preserve existing behavior unless an approved specification changes it.
8. Completion requires verification evidence.
9. Git operations must never include unrelated work.
10. Do not add rules, skills, hooks, workflows, or abstractions without repeated evidence that they are needed.
