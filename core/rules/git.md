# Git rule

## Scope

Applies to version-control operations performed during a task.

## Rules

- Inspect the branch and working tree before changing or staging files.
- Treat existing unrelated changes as user-owned and leave them untouched.
- Review the diff and stage explicit task paths only.
- Keep commits coherent, scoped, and free of unrelated work.
- Do not rewrite, discard, merge, or publish history unless the task explicitly authorizes it.
- Verify the working tree and commit range before reporting completion.
